# Exam Key Club Web App

यह एक standalone mobile-first prototype है।
- `index.html` सीधे browser में खोल सकते हैं।
- कोई external library आवश्यक नहीं है।
- Responsive mobile/desktop UI
- Search/filter
- Category navigation
- Promotional carousel
- Course cards
- Modal screens
- Bottom mobile navigation

Production version में Supabase, login/OTP, Razorpay/UPI, video/PDF protection, test engine और admin panel जोड़े जा सकते हैं।
